# 外贸运行调度台账

记录外贸货物、企业诉求和分级调度形成可解释统计。

## 领域资料

`contracts/domain.schema.json` 规定共享资料结构，`fixtures/domain.json` 保存不含真实个人信息的示例。当前参与方包括省级商务部门、市州调度人员、外贸企业、货运协调人员。

资料所依据的领域事实如下：

- 当地建立日监测周调度机制
- 重点企业接受一企一策服务
- 特色产品出口与原料进口共同影响外贸运行

## 本地校验

仓库内的读取模块负责校验示例资料的领域标识、版本、参与方、事实和约束。运行项目自带测试即可检查这些基础资料能够稳定读取。仓库不保存账号、密钥、连接串或真实身份信息。
