# 外贸运行调度台账

记录外贸货物、企业诉求和分级调度形成可解释统计。

## 领域资料

`contracts/domain.schema.json` 规定共享资料结构，`fixtures/domain.json` 保存不含真实个人信息的示例。当前参与方包括省级商务部门、市州调度人员、外贸企业、货运协调人员、口岸数据提供方。

资料所依据的领域事实如下：

- 当地建立日监测周调度机制
- 重点企业接受一企一策服务
- 特色产品出口与原料进口共同影响外贸运行
- 进口在三十二个月后恢复两位数增长
- 热带水果、矿石原料、冷水鱼和盐湖化工是重点监测品类
- 同一票货物可能由企业、市州或口岸多方重复报送
- 部分报关结果迟于所属统计期间才获知
- 月末汇总无法支撑日监测和周调度的时效要求

## 日监测平台规则

`platform` 小节规定贯通企业、市州和省级部门的日监测平台应遵守的共享规则：

- **归并去重**：同一票货物以报关单号为唯一标识，无论由谁报送只计一次。
- **迟到数据**：迟到的报关结果归入实际统计期间，并注明获知时间。
- **版本保留**：已经发布的口径与结论保留原版本，修订生成新版本。
- **分级视图**：企业登录后只处理自身申报和服务事项；市州承担辖区协调；省级视图能沿着每个增减值下钻到货物、商品类别与数据来源。
- **承诺闭环**：一企一策形成的责任人、承诺期限和办理结果进入下一次周研判，而不是散落在会议纪要里。

## 本地校验

仓库内的读取模块负责校验示例资料的领域标识、版本、参与方、事实、约束和平台规则。运行项目自带测试即可检查这些基础资料能够稳定读取。仓库不保存账号、密钥、连接串或真实身份信息。
